这是一篇示例博文，演示博客支持的写法。它所在的文件夹名以 `_` 开头，算草稿，所以只在本地 `npm run serve` 时出现，**不会发布到线上**。可以照着它写新文章，写完把这个文件夹删掉即可。

## 新建一篇文章

1. 在 `src/posts/` 下新建一个文件夹，文件夹名就是网址，例如 `my-first-post` → `/blog/my-first-post`。
2. 在文件夹里新建 `index.md`，开头写上标题和日期：

```markdown
---
title: 我的第一篇博文
date: 2026-10-10
---

正文从这里开始……
```

3. 想先不发布，就在文件夹名前加 `_`（如 `_my-first-post`），它就是草稿，只在本地显示。写好后把 `_` 去掉即可发布，网址不变。

## 插入图片

把图片放进文章自己的文件夹，用相对路径引用。VS Code 里也可以直接把图片拖进或粘贴到编辑器，它会自动复制到这个文件夹并写好链接：
